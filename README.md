# Sabores do Paraná

Site em React para apresentar pratos típicos do Paraná e montar orçamentos para eventos.

## Rodar localmente

```bash
npm install
npm run dev
```

## Gerar build

```bash
npm run build
npm run preview
```

O site é publicado no GitHub Pages em [MatheSam/sabores_parana](https://MatheSam.github.io/sabores_parana/). A publicação é automatizada pelo GitHub Actions a cada atualização da branch `main`.
